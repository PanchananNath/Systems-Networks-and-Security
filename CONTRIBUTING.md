# Contributing

Thanks for helping improve this repo.

## What's welcome

- Corrections (wrong facts, broken links, typos)
- New notes, paper notes, reading-list items
- New labs that follow the [lab template](./05-labs/_template/)

## Conventions

- **Folders:** numbered, lowercase, hyphenated (`03-security/02-cryptography/`).
- **Files:** lowercase, hyphenated, `.md`. Every folder has a `README.md`.
- **Notes:** use the templates in [`templates/`](./templates/).
- **Links:** relative links inside the repo; cite sources for factual claims.
- **Commits:** [Conventional Commits](https://www.conventionalcommits.org), e.g. `docs(security): add 5G-AKA notes`, `feat(labs): add raft lab`.
- **One home per topic:** if something fits two sections, put it in one and link from the other.

## Process

1. Open an issue for anything larger than a small fix.
2. Fork, create a branch, make your change.
3. Open a pull request using the template.

## Security content

Read [SECURITY.md](./SECURITY.md). Pull requests containing weaponised exploits for unpatched vulnerabilities, malware samples, or credentials will be closed.
