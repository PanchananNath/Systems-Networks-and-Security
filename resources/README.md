## Standards bodies & primary sources

- [RFC Editor](https://www.rfc-editor.org/) — Internet standards

- [NIST CSRC](https://csrc.nist.gov/publications) — security standards and guidelines
- [OWASP](https://owasp.org/) — application security projects
- [MITRE ATT&CK](https://attack.mitre.org/) and [ATLAS](https://atlas.mitre.org/) — adversary tactics for IT and AI systems
