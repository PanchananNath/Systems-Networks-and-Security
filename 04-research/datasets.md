# Datasets & testbeds

Check each dataset's licence and known limitations before using it in a paper.

## Network traffic & intrusion detection

| Dataset | Source | Notes |
|---|---|---|
| [CIC-IDS2017](https://www.unb.ca/cic/datasets/ids-2017.html) | Canadian Institute for Cybersecurity, UNB | Labelled flows with modern attacks |
| [UNSW-NB15](https://research.unsw.edu.au/projects/unsw-nb15-dataset) | UNSW Canberra | Labelled traffic, 9 attack families |
| [CTU-13](https://www.stratosphereips.org/datasets-ctu13) | Stratosphere Lab, CTU Prague | Botnet captures |
| [NSL-KDD](https://www.unb.ca/cic/datasets/nsl.html) | UNB | Historic baseline only — widely criticised as outdated |
| [CAIDA](https://www.caida.org/catalog/datasets/) | UC San Diego | Internet backbone traces and topology |
| [MAWI](https://mawi.wide.ad.jp/mawi/) | WIDE Project | Daily backbone traces |
