# Datasets & testbeds

Check each dataset's licence and known limitations before using it in a paper.

## Network traffic & intrusion detection

| Dataset | Notes |
|---|---|
| CIC-IDS2017 / CSE-CIC-IDS2018 | Labelled flows with modern attacks (Canadian Institute for Cybersecurity) |
| UNSW-NB15 | Labelled network traffic, 9 attack families |
| CTU-13 | Botnet traffic captures |
| NSL-KDD / KDD Cup 99 | Historic baseline only — widely criticised as outdated |
| CAIDA, MAWI | Real Internet backbone traces |
