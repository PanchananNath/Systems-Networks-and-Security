# 04 · Research

Where study turns into research: reading papers systematically, tracking venues, and keeping research artefacts reproducible.

| Folder / file | Purpose |
|---|---|
| [`paper-notes/`](./paper-notes/) | One note per paper, using the [paper-note template](../templates/paper-note.md) |
| [`reading-lists/`](./reading-lists/) | Curated, ordered reading lists per research area |
| [`surveys/`](./surveys/) | Notes on survey/SoK papers — the fastest way into a new area |
| [`ideas.md`](./ideas.md) | Open problems and project ideas |
| [`venues.md`](./venues.md) | Conferences and journals per area |
| [`datasets.md`](./datasets.md) | Public datasets and testbeds |
| [`methods.md`](./methods.md) | Reading, writing, experiments and reproducibility |

## Workflow

1. Find papers via venues, surveys and citation chasing.
2. Write a short note per paper in `paper-notes/` (`YYYY-venue-shortname.md`).
3. Link it from the relevant reading list and topic folder.
4. Log gaps and limitations you notice in `ideas.md` — that list becomes your future projects.
