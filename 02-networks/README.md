## Suggested learning path

1. Fundamentals → Internet Protocols
2. Measurement & Simulation (the tools you'll use for every experiment)
3. Pick a track: **SDN/NFV → Mobile 5G/6G**, **Wireless/IoT**, or **Data Center**
4. AI for Networking once you have one track down
