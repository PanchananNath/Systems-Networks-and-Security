# Security policy & responsible use

## Educational purpose

Security material in this repository is for **learning, research and authorised testing only**.
Run offensive techniques only against systems you own or have explicit written permission to test.

## What this repo will not host

- Working exploits for unpatched vulnerabilities in real products
- Live malware samples (link to vetted repositories with appropriate warnings instead)
- Credentials, API keys, private keys or personal data

## Reporting

If you find a problem **in this repository** (e.g. a committed secret or unsafe content), please contact the maintainer privately via GitHub rather than opening a public issue.

If you discover a vulnerability in third-party software while using these materials, follow that vendor's coordinated-disclosure process.
