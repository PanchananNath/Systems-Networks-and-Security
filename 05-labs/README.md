# 05 · Labs

Hands-on, reproducible exercises. Each lab lives in its own folder:

```
05-labs/<area>-<short-name>/
├── README.md        # goal, prerequisites, steps, expected results
├── Dockerfile       # or setup.sh — environment in one command
├── src/
└── results/         # outputs and plots (small files only)
```

Start from [`_template/`](./_template/).

## Rules

- Everything runs in a container, VM or isolated lab network.
- Offensive-security labs target only your own sandbox. Never target systems you don't own or aren't authorised to test.
- No secrets, keys or credentials in commits.
