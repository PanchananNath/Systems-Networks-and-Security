# Blockchain & DLT Security

> **Section:** 03 · Security · **Level:** Intermediate → Advanced

Consensus, smart contracts and decentralised applications.

## Core subjects

- [ ] Blockchain fundamentals: PoW, PoS, BFT consensus
- [ ] Consensus and network attacks: selfish mining, eclipse, 51%
- [ ] Smart-contract vulnerabilities: reentrancy, integer bugs, access control
- [ ] Permissioned ledgers (Hyperledger Fabric)
- [ ] Blockchain for networking (decentralised marketplaces, trust/reputation)
- [ ] Smart-contract analysis tools (Slither, Mythril)
