# Data Structures & Algorithms

> **Section:** 00 · Foundations · **Level:** Beginner → Advanced

The algorithmic toolkit every systems, networking and security problem eventually reduces to.

## Core subjects

- [ ] Asymptotic analysis, recurrences, amortised analysis
- [ ] Arrays, linked lists, stacks, queues, hashing
- [ ] Trees: BST, AVL/Red-Black, B-trees, tries, heaps
- [ ] Graphs: BFS/DFS, shortest paths, MST, max-flow
- [ ] Divide & conquer, greedy, dynamic programming
- [ ] Randomised algorithms, bloom filters, sketches
- [ ] NP-completeness and approximation basics

## Key references

- Cormen, Leiserson, Rivest, Stein — *Introduction to Algorithms* (CLRS)
- Kleinberg & Tardos — *Algorithm Design*
- Skiena — *The Algorithm Design Manual*

## Lab ideas

- Implement a B-tree and benchmark it against a hash map
- Dijkstra vs. Bellman-Ford on a real router topology
- Count-Min sketch for heavy-hitter detection on a packet trace
