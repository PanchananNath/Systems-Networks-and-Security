# Discrete Math, Probability & Linear Algebra

> **Section:** 00 · Foundations · **Level:** Beginner → Intermediate

Math underpinning cryptography, queueing, performance modelling and ML-for-systems.

## Core subjects

- [ ] Logic, sets, proofs, induction
- [ ] Number theory: modular arithmetic, primes, groups, finite fields
- [ ] Combinatorics and graph theory
- [ ] Probability, random variables, common distributions
- [ ] Queueing theory basics (M/M/1, Little's law)
- [ ] Linear algebra for ML (vectors, matrices, SVD)
