# Programming: C, Rust, Python, C++

> **Section:** 00 · Foundations · **Level:** Beginner → Intermediate

Languages used throughout the repo: C for systems, Rust for safe systems code, Python for tooling and ML, C++ for LLVM/MLIR.

## Core subjects

- [ ] C: pointers, memory layout, undefined behaviour
- [ ] Rust: ownership, borrowing, lifetimes, unsafe
- [ ] Python: scripting, packaging, numpy/pandas, PyTorch basics
- [ ] C++: RAII, templates, the subset used by LLVM/MLIR
- [ ] Build systems: Make, CMake, Cargo
- [ ] Debugging: gdb, valgrind, sanitizers (ASan/UBSan)
